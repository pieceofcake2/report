A4 PDF reports printed by the command line of a headless Chrome: a cover with the result, a list of the items
by group, and a page for each item. It is the report of [pieceofcake2/panther](https://github.com/pieceofcake2/panther)
and of the security checks of pieceofcake2.

## Documentation

- Website: https://pieceofcake2.github.io/report/ (日本語: https://pieceofcake2.github.io/report/ja/)
- Markdown: [docs/README.md](docs/README.md) (日本語: [docs/ja/README.md](docs/ja/README.md)) (for AI tools and offline reading)

## Requirements

* PHP 8.0+
* Google Chrome or Chromium 131+

## Installation

```bash
composer require pieceofcake2/report
```
